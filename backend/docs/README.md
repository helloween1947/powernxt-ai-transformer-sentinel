# Backend Documentation

This directory contains technical notes, architecture design records, and internal specifications for the PowerNXT Transformer Sentinel backend service.

## Key References
- Data contracts are defined centrally in the project root: `docs/contracts/`
- API documentation is auto-generated by FastAPI at runtime:
  - Swagger UI: `http://localhost:8000/docs`
  - ReDoc: `http://localhost:8000/redoc`
  - OpenAPI JSON specification: `http://localhost:8000/openapi.json`
