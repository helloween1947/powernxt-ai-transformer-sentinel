## 2. Model 1.0.2 Schema Compatibility & Rendering

1. **Telemetry Stream Display**:
   - Telemetry adapter correctly parses 3-phase electrical fields (`voltage_r_v`, `voltage_y_v`, `voltage_b_v`, `current_r_a`, `current_y_a`, `current_b_a`) and thermal values (`oil_temperature_c`, `ambient_temperature_c`).
   - Disallowed extra fields fail visibly without crashing the UI.
2. **Thermal Residual & Bootstrap Visualization**:
   - Cold-start bootstrap readings correctly display `predicted: "Unavailable"` and `residual: "Unavailable"` instead of fabricating zero or misleading values.
   - Subsequent valid predictions render signed residual metrics (`+X.X°C` or `-X.X°C`) with clear visual distinction.
3. **Multi-Model Coexistence**:
   - The UI seamlessly distinguishes historical Model 1.0.1 records (`run_id="model-1.0.1-run-001"`) from live Model 1.0.2 streams without cross-contamination.

---

## 3. Transparency & Uncalibrated Parameter Indicators

1. **Model Parameter Badging**:
   - Thermal parameters (`rated_top_oil_rise_c`, `oil_time_constant_min`, `loss_ratio`, `oil_exponent`) are prominently tagged with an **"Assumed / Uncalibrated"** warning badge.
2. **What-if Simulator Disclaimer**:
   - Projections generated by the interactive What-if simulation slider display the mandatory operational disclaimer:
     > *"Conditional healthy-model estimates under constant-load assumptions."*
   - UI clearly communicates that projections do not represent field sensor truth or active cooling intervention.

## 4. Stale Analytics Refresh Resilience (PR #33)

1. **Refresh Failure Handling**:
   - When a polling request fails (e.g. 503 or network disconnect) following a pending state, the frontend immediately clears stale analytics indicators while preserving previously ingested telemetry readings.
   - Verified by automated test: `✔ failed pending refresh clears retained analytics while keeping previously retrieved telemetry`.
2. **Stream Switching**:
   - Switching transformer stream filters aborts in-flight network requests cleanly and avoids race condition overwrites.
