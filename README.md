# Transformer Sentinel

An explainable transformer digital twin for monitoring,
forecasting, scenario comparison, and maintenance support.

## Team responsibilities

- Person A: Backend, ingestion, database, and simulator
- Person B: Digital twin and analytics
- Person C: Frontend and visualization
- Person D: Integration, validation, and maintenance

## Project folders

- backend/
- analytics/
- frontend/
- integration/
- docs/
- data/sample/

## Collaboration

Create a feature branch for each task.
Open a pull request when the change is ready.
Ask another teammate to review before merging into main.
